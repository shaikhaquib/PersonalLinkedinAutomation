# Universal LinkedIn Content Optimizer Skill

Apply this skill whenever the user provides a raw draft or topic idea intended for publication to an executive or technical audience on LinkedIn.

## Core Transformation Principles

1. **The 3-Line Cutoff Rule:**
   - Force the first 1-2 lines to explicitly highlight a painful problem, a major risk, an engineering nightmare, or a counter-intuitive finding.
   - Do not use filler introductions (e.g., "I wanted to share...", "In today's fast-paced world..."). Capture attention immediately before the user scrolls past.

2. **Dwell-Time Layout Architecture:**
   - Convert dense paragraphs into single, punchy sentences. White space keeps users on the platform longer.
   - Use visual anchors like 1️⃣, 2️⃣, 3️⃣ for sequential breakdowns or technical steps.
   - Group item names cleanly using bold lead-ins.

3. **CTA Consolidation:**
   - Audit the end of the post. Strip out competing options.
   - Provide *one single* call to action—preferably a thought-provoking, high-level question that incentivizes comments (which drives feed acceleration).

4. **Formatting Sanitation:**
   - Never place hyperlinks inside the body of the post.
   - Force all hashtags to the absolute bottom of the output using period spacers (`.`).

## Expected Output Generation Format

```text
[High-stakes, problem-driven hook sentence]

[Context or compounding complication sentence]

1️⃣ [Technical Insight One]

2️⃣ [Technical Insight Two]

**The Core Fixes / Takeaways:**
• [Actionable point]
• [Actionable point]

💡 [Singular, conversational prompt for technical leaders]

.
.
.
#HashtagsGoHere
```
